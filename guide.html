1. 처음 한 번만 - 접속하기

1
인터넷 주소창에 labelcheck.dkmdkm999.workers.dev 를 입력합니다. 휴대폰·태블릿·컴퓨터 어디서나 됩니다.
2
접속 코드를 입력합니다. 코드는 관리자(곽동신)에게 받으세요.
3
즐겨찾기(북마크)에 추가해 두면 다음부터 바로 열립니다. 접속 코드는 한 번 넣으면 같은 기기에서는 다시 묻지 않습니다.
화면 왼쪽이 입력하는 곳, 오른쪽이 결과가 나오는 곳입니다. 이것만 기억하면 됩니다.

2. 일 순서 ① 거래처 자료가 오면 - 정보 불러오기 무료

거래처가 품목제조보고서나 보고번호를 보내오면, 타이핑할 필요 없이 식약처 공식 데이터베이스에서 바로 불러옵니다.

1
식품안전나라 조회 칸에서 종류를 고릅니다 — 보고번호(제일 정확), 제품명(번호를 모를 때), 바코드(실물만 있을 때).
2
번호나 이름을 넣고 조회를 누르면 제품명·식품유형·제조사·소비기한·포장재질·원재료가 나옵니다.
3
결과 아래 입력창에 넣기를 누르면 검수 입력창에 자동으로 들어갑니다.
이 조회는 AI를 쓰지 않아서 몇 번을 눌러도 비용이 0원입니다. 부담 없이 쓰세요.
같은 칸에서 회수·판매중지와 행정처분(업체)도 조회됩니다. 새 거래처와 일을 시작하기 전에 업체명을 한 번 검색해 보면 최근 처분 이력을 확인할 수 있습니다.

3. 일 순서 ② 표기사항 초안 만들기 - 엑셀 자동 생성 AI 사용

품목제조보고서와 영양성분 성적서로 컬러박스에 인쇄할 한글표기사항 엑셀을 자동으로 만듭니다.

1
파일 첨부 칸에 품목제조보고서(PDF·사진·AI파일)를 넣습니다. 영양 성적서가 있으면 같이 넣으세요.
2
표기사항 엑셀 만들기 버튼을 누릅니다.
3
1~2분 뒤 회사 서식(주표시면·정보표시면·배합비율)에 맞춘 엑셀 파일이 내려받아집니다. 열어서 확인·수정 후 사용하세요.
자동 생성된 엑셀은 초안입니다. 보고번호·원재료 배합비율 숫자는 반드시 원본 보고서와 눈으로 대조하세요.

4. 일 순서 ③ 디자인 시안·문구 검수하기 AI 사용

디자인 업체가 보낸 시안이나 상세페이지 문구가 규정에 걸리는지 확인합니다. 가장 많이 쓰는 기능입니다.

1
검수 기준을 고릅니다 — 일반식품 / 건강기능식품 / 수출(미국·일본).
2
문구를 입력창에 붙여넣거나, 시안 파일(이미지·PDF·AI)을 첨부합니다. 파일만 넣어도 됩니다. 사진 속 글씨를 먼저 확인하고 싶으면 사진 속 문구 읽어오기를 누르세요.
3
검수하기를 누릅니다.
4
오른쪽에 결과가 두 층으로 나옵니다.
· 즉시 감지 무료 — 금칙어, 알레르기 표시 누락, 바코드 오타, 식약처 등록정보와 다른 부분을 기계적으로 잡습니다. 입력에 보고번호나 바코드가 있으면 공식 DB와 자동 대조하고 회수·판매중지 이력까지 자동 확인합니다.
· AI 검수 결과 — 규정 원문을 근거로 위반 위험을 높음·중간·낮음으로 나눠 설명하고, 수정 문안을 제안합니다.
수정 문안 추천을 켜 두면(기본 켜짐) 위반 문구를 규정에 맞게 고친 대체 문안까지 받아볼 수 있어 디자인 업체에 그대로 전달하기 좋습니다.
정밀 검수는 더 꼼꼼하지만 비용이 2~5배입니다. 최종 시안이나 까다로운 제품에만 켜세요.

5. 일 순서 ④ 인쇄 직전 최종 점검 무료

인쇄 넘기기 전, 비용이 들지 않는 마지막 안전장치 세 가지를 확인하세요.

1
바코드 — 최종 시안 문구를 넣고 검수하면 즉시 감지가 바코드 숫자 오타(체크섬)를 자동 확인합니다. 바코드 오타는 인쇄 후 발견되면 재인쇄 비용이 가장 큰 항목입니다.
2
알레르기 표시 — 원재료명에 우유·대두·밀 같은 성분이 있는데 "○○ 함유" 표시가 없으면 자동으로 경고가 뜹니다.
3
회수 이력 — 보고번호가 입력에 있으면 회수·판매중지 목록과 자동 대조됩니다.

6. 보조 도구

영양성분표 계산기 무료

검사성적서의 100g(ml)당 값과 1회 제공량을 넣으면, 식약처 표시기준의 반올림 규칙과 1일 기준치 비율(%)을 자동 적용한 패키지 표시값을 만들어 줍니다. 지금까지 외주에 맡기던 계산이 3초에 끝납니다.

왼쪽 아래 접힌 메뉴를 누르면 열립니다. 성적서 값을 그대로 입력하세요 — 반올림하지 말고 소수점까지 그대로.

식품안전나라 조회 무료

조회 종류언제 쓰나
보고번호품목제조보고번호로 공식 등록정보 + 원재료를 불러올 때
제품명번호를 모를 때, 비슷한 시중 제품의 표기를 참고할 때
바코드실물 제품만 있을 때 등록 제품 확인
회수·판매중지제품·업체·번호로 회수 이력 확인 (현재 유통 회수 목록)
행정처분(업체)거래처 업체명으로 최근 행정처분 확인

7. 함께 쓰기 - 이력 공유 · 문안 공유 · 문의

1
검수 이력 — 검수할 때마다 자동 저장되고 접속 코드를 아는 전원이 같은 이력을 봅니다. 왼쪽 아래 "최근 검수 이력"에서 검색창으로 제품명을 찾아 클릭하면 그때 결과가 다시 열립니다. 불러와서 수정 후 재검수도 됩니다.
2
문안 공유 저장 — 작업 중인 문구를 이름 붙여 저장하면 상대방이 열어 보고 이어서 수정할 수 있습니다. "사장님 확인 부탁" 같은 용도로 쓰세요.
3
문의하기 — 궁금한 점을 남기면 관리자 카카오톡으로 즉시 알림이 갑니다.

8. 비용과 한도

기능비용
식품안전나라 조회 · 영양 계산기 · 즉시 감지(알레르기·바코드·금칙어·공식DB 대조)전부 무료
검수하기 1회약 10~30원
OCR·엑셀 생성 1회약 50~150원
정밀 검수 1회약 50~150원

월 최대치로 써도(품목 50개 × 4~5회) 월 2~3만원 수준입니다. 하루 150회 사용 한도가 있어 요금이 폭주할 일은 없습니다. 한도에 걸리면 "내일 다시 이용해주세요"라고 안내가 뜹니다.

9. 자주 묻는 질문

Q. AI 검수 결과를 그대로 믿어도 되나요?

참고용 1차 검수입니다. 규정 원문을 근거로 짚어 주지만 최종 판단과 책임은 사람의 몫입니다. 특히 "높음"으로 표시된 항목은 반드시 원문 규정을 확인하세요. 반대로, 기계적으로 확인되는 것(바코드 체크섬, 공식 DB 대조, 영양 반올림 계산)은 규칙 그대로 계산한 것이라 믿고 쓰셔도 됩니다.

Q. 파일은 어떤 형식이 되나요?

사진(JPG·PNG), PDF, 일러스트(AI) 파일이 됩니다. 세로로 긴 패키지 전개도나 큰 파일은 자동으로 나눠서 읽습니다.

Q. 검수 이력이 거래처에 보이나요?

아니요. 접속 코드를 아는 사람만 볼 수 있습니다. 다만 이력은 팀 전체가 공유하므로 대외비 자료는 검수 후 이력에서 삭제할 수 있습니다(이력 항목 열어서 삭제 버튼).

Q. 조회가 안 되거나 오류가 나면?

화면의 문의하기로 남겨 주세요. 관리자 카카오톡으로 바로 전달됩니다.
